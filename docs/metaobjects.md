# Metaobject Definitions

## Review
- Reviewer name — Single line text
- Rating — Integer
- Review body — Multi-line text
- Product — Reference (Product, single)
- Date — Date

## Combo
- Title — Single line text
- Products — Reference (Product, list)
- Combo price — Number (decimal)
- Image — File
